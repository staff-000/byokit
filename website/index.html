import * as byokit from
  'byokit/catalog';

const key = process.env.DEEPSEEK_API_KEY;
if (!key) throw new Error('Set DEEPSEEK_API_KEY');
const [model] = byokit.getModels(byokit.DEFAULT, {
  providerIds: byokit.exact(byokit.ProviderId.DeepSeek),
  sort: byokit.ModelSort.PriceAscend,
  limit: 1, local: false,
});
if (!model?.connection) throw new Error('No model');
const result = await byokit.call(
  model, 'Hello', key,
);
console.log(result.choices[0].message.content);

01

Discovery + execution in two calls

One simple call to get an up-to-date list of BYOK models, and one simple call to run inference. No provider-specific SDK glue required.

02

Presets, composable matchers & rich filters

Curated presets paired with composable matchers (exact, any, contain, exclude, and, or, xor, not) for modalities, required speciality, model tiers, context, and tag exclusions. Existing array filters remain supported.

03

Regular releases & verification

Automated 12-hour sync and scheduled releases keep catalog choices current, backed by reproducible community inference verification and badges.

04

Credential privacy by default

Built-in calls keep keys in memory and send them directly to the selected endpoint. Custom storage and transport integrations remain under your app’s control.

05

Build-time generation & caching

Generate a smaller static model list for fixed queries. Dynamic queries use a bundled snapshot and deterministic in-memory caching.

06

Pre-flight task & budget fit

Validate token budgets, context limits, features, and modalities before sending tokens or incurring API costs.

07

Complete cross-language parity

Full parity across JavaScript/TypeScript and Python with shared schemas, enums, query outcomes, and budget checking.

04 / HOW TO CALL THE API

Get your list.
Then call your model.

Select an offering, provide that provider’s key, and call it. The direct helper reads its endpoint and protocol; reusable clients need both fields explicitly.

Catalog queries run offline. No API key or provider request is needed.

Full instructions in README ↗

Use your existing OpenAI / Anthropic SDK ↗ 

import * as byokit from 'byokit';

const key = process.env.DEEPSEEK_API_KEY;
if (!key) throw new Error('Set DEEPSEEK_API_KEY');

const [model] = byokit.getModels(byokit.DEFAULT, {
  providerIds: [byokit.ProviderId.DeepSeek],
  local: false,
  limit: 1,
  filters: { callable: true },
});
if (!model?.connection) throw new Error('No matching callable model');

const response = await byokit.call(model, 'Hello!', key);
console.log(response.choices[0].message.content);

An array of provider/model metadata.

INTEGRATION CONTRACT

Use the offering.
Keep its protocol.

Copy a runnable example, then preserve these fields when wiring it into your app.

One object or three client fields

Pass the entire model to byokit.call(model, prompt, key). With a BYOKit client, copy connection.baseUrl and connection.protocol, then send apiModelId as the request’s model string. The offering’s id is for selection and records.

Discovery is not a successful call

DEFAULT provides maintained recommendations. COMPLETE includes unsupported, deprecated, and media offerings. callSupport.textGeneration means adapter compatibility; account access, quota, lifecycle, and verification are separate.

Local setup sends no requests

Enter URL, protocol, and the exact served model ID, then choose Use this model. The returned Local entry is ready for call(). Finding models and verifying are explicit actions. Image/audio/video generation and streaming execution are not supported.

The key belongs to the provider

Use the selected providerId’s key, including for resellers. Built-in calls keep it in memory and require HTTPS for authenticated remote servers; loopback HTTP supports local development. Custom storage adapters can persist keys. Python clients block credential serialization.

05 / PRODUCTION OPTIMIZATION

Build-time precompilation.

Pre-evaluate fixed model queries at build time.
Ship only the offerings your application needs.

1

Declare your query

Save from the explorer/playground above via Save config.json, generate with byokit.getConfigJson(), or write byok.config.json: 

{
  "providerIds": [
    "anthropic",
    "google",
    "openai",
    "deepseek"
  ],
  "local": false,
  "filters": {
    "includeTags": ["model:flash"]
  }
}
2

Compile once

Evaluate your query at build time:

# Node / TS:
npx byokit build byok.config.json \
  --out src/generated/models.js

# Python:
byokit build byok.config.json \
  --out app/generated_models.py
3

Import the generated list

Pair the generated model list with byokit/client:

// JavaScript / TypeScript:
import { getModels } from './generated/models.js';
import { call } from 'byokit/client';

const model = getModels().find(m =>
  m.providerId === 'google');
if (!model) throw new Error('No Google model');
const key = process.env.GOOGLE_API_KEY;
if (!key) throw new Error('Set GOOGLE_API_KEY');
const result = await call(model, 'Hello', key);

byokit.getModels() queries a bundled snapshot offline. Precompiling a fixed query removes the full catalog and query evaluation from your application’s runtime; generated file size depends on the selected offerings.
